# Topic: 个人学习工作台重构

> capsule：把前端从"只读看板"重构为"个人学习工作台"——人是一等操作者，围绕日常节奏（今天 → 记录 → 学习库 → 回顾）。保留 split-flap 视觉。

## 现状问题

- 4 个平级 tab（计划/出发板/进度/站务），无"今天"锚点
- 记录动作（建卡/开目标）埋在小表单里，不显眼
- 学习库（目标→路径→模块）一层层点开，维护费劲
- 看板感强、工作台感弱

## 新布局

围绕人的一天（单页流，或"今天"为主页）：

1. **今天**：今日待复习/新卡/已学/streak + 今日时间线 + `[开始复习]` `[学新卡]`
2. **学习库**：目标 → 路径 → 模块 → 卡 的树，可展开 / 内联编辑 / 建删
3. **回顾**：热力图 / 领域分布 / 会话（复用 ProgressView）

顶部常驻 **＋ 快捷记录**：记卡 / 开目标 / 记笔记，一键弹小表单。

## 后端支持

- 新增 `GET /api/timeline`：聚合"今天的活动"（sessions + review_logs + 今日建卡），时间倒序。纯派生，数据模型不变。

## 影响面

- 后端：`main.rs` 加 timeline 端点 + `repo.rs` 加聚合函数
- 前端：`App.tsx` 布局重构 + `QuickCapture` / `TodayView` / `LibraryTree` 新组件 + `api.ts`/`types.ts` 加 timeline 类型
- 保留：`styles.css` 视觉、现有 API、数据模型

## 边界（本期不做）

- 拆解引导（半自动拆路径）——后续单独做
- 移动端 / Docker / AI 接入（MCP）
- 数据模型改动
