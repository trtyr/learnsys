## 职责边界（核心原则）

> **确定性的归平台，需要理解和生成的归 AI。**

| 归平台（确定性） | 归 AI（智能） |
|---|---|
| SM-2 调度：复习质量分 → 下次到期 | 诊断用户目标/水平/场景 |
| 统计聚合：待复习数、留存率、热力 | 苏格拉底/费曼式教学引导 |
| 卡片/进度/会话的 CRUD + 持久化 | 生成卡片内容（出题、写答案） |
| 测验题目的机械抽取 | 判断用户复述的质量分(0-5) |
| 到期提醒数据 | 决定下一步学什么 |

关键：**SM-2 算法留在平台**（纯数学），AI 只负责把复习结果（q 分）喂给平台。

## 一个学习闭环（数据流）

```
①AI 诊断  → POST /progress          ④AI 取今日复习 → GET /cards/due
②AI 做卡  → POST /cards              ⑤AI 带回忆,q分 → POST /cards/:id/review
③平台 SM-2 排期(无人参与)            ⑥平台算下次到期,存回
                                      ⑦展示层读同份数据 → GET /stats
```
